Flashcards are an effective tool for active recall and work well as quick knowledge checks for facts, definitions, formulas, and other key information.

The navigation buttons let users move through the cards, shuffle the deck, flip individual cards, or flip the entire deck at once.

Developer Notes

The flashcards table supports the following CSS classes for customization:

  • no-number - Removes card numbering from the display
  • no-nav - Removes navigation controls from the flashcards

These classes can be applied to the table element to modify the default behavior and appearance of the flashcard interaction.
