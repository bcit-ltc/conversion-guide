Line-Matching The line-matching activity is a simple, on-page self-assessment that requires the user to pair items from two different lists (e.g. matching definitions to terms). Each item in the list can have one (1-to-1 matching) match. On a desktop, a user drags a line to connect an item to its correct match. On mobile interfaces, the user simply clicks to match up items.

Match the following academic programs to the appropriate School at BCIT.

#line-matching

Match the following academic programs to the appropriate School at BCIT.

/line-matching

The order of the matching terms is automatically randomized.

Text Length

Ideally, text for both questions and answers should be kept to a maximum of 140 characters.

Large amount of text will have a reduced font size and may not provide the best user experience for students when using this interaction.

Multimedia

While multimedia elements like images and videos can be accommodated into this interaction, it is not recommended as size restrictions will prevent them from being rendered in their best quality.
